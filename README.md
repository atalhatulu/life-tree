# Life Tree

Procedural life simulation prototype.

## Current foundation

- Seeded deterministic RNG
- Procedural parents, grandparents and siblings
- Parent-derived genetics and childhood interests
- Household income and economic class
- Condition-based event engine
- Year progression
- Minimal browser UI
- Node test suite

## Run

```bash
npm test
python3 -m http.server 8080
```

Open http://localhost:8080.
